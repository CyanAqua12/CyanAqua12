## Illustration
<img src="https://cyanaqua.neocities.org/images/drawings/sky_and_sea.png" width=200px>

My main hobby. I mostly draw **Renko Usami** and **Maribel Hearn** from Touhou project in various artstyles.

- [Bluesky](https://bsky.app/profile/cyanaqua.bsky.social)
  - Main social media account, all recent Touhou illustrations are uploaded here.
- [Twitter](https://x.com/CyanAqua1)
  - Secondary social media account, used as both an archive of my more recent drawings, and a repost account for other Hifuu artwork I come across.
- [Pixiv](https://www.pixiv.net/en/users/76982948)
  - Tertiary social media account, mostly used as an archive of my drawings. Mostly identical to the drawings on Bluesky.
- [Neocities](https://cyanaqua.neocities.org/)
  - Art dump website, where I reveal my thought process the most. Lags behind Bluesky and Pixiv, but has a lot of detailed explanations. Note that a lot of older drawings have missing pages.
- [Discord Server](https://discord.gg/9CSc6Vqx7g)
  - Mostly dead server where I occasionally upload illustrations.
 
## Game Dev
[Sealed Secrets Journal Demo on itch.io](https://cyanaqua.itch.io/sealed-secrets-journal)

I make Touhou fangames, usually involving Renko and Maribel. A public demo for ***Sealed Secrets Journal*** is currently available to play, and I am working on a new project called ***Hifuu Hecatolite Historia ~ Magical Night Flight*** as of now.

I've also worked with other amazing people like **M1n3c4rt**, **TENEX_KEZIKAI**, **TeoCPerfectForm** and **0mni** as an artist for GMTK Game Jam submissions like [OXVN](https://m1n3c4rt.itch.io/oxvn) and [XCUIT](https://m1n3c4rt.itch.io/xcuit).

- [itch.io](https://cyanaqua.itch.io/)
  - My main account for game dev. All my publicly available games are and will be uploaded here.
- [Github](https://github.com/CyanAqua12)
  - This website right here! Currently holds the repository for *Hifuu Hecatolite Historia ~ Magical Night Flight*.
