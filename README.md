## Illustration
<img src="https://cyanaqua.neocities.org/images/drawings/nap.png" width=200px>

My main hobby is drawing! More specifically, drawing these illustrations every once in a while. I intentionally try to draw experimentally, so you'll be able to see drawings in all sorts of styles. My drawings mostly consist of **Renko Usami** and **Maribel Hearn**, my two favorite characters from Touhou, although you may rarely come across other characters I find interesting. As my primary hobby, most of my social media is focused around drawing, which you can find here:

- [Bluesky](https://bsky.app/profile/cyanaqua.bsky.social)
  - Main social media account, all recent Touhou illustrations are uploaded here.
- [Pixiv](https://www.pixiv.net/en/users/76982948)
  - Secondary social media account, mostly used as an archive of my drawings. Mostly identical to the drawings on Bluesky.
- [Neocities](https://cyanaqua.neocities.org/)
  - Art dump website, where I reveal my thought process the most. Lags behind Bluesky and Pixiv, but has a lot of detailed explanations. Note that a lot of older drawings have missing pages.

  - Used to just be an account for shitposting, but picked back up recently. Acts mostly as a backup to Bluesky and Pixiv.

## Gaming

Another one of my biggest hobbies. As an aspiring solo game dev, I have a deep appreciation for indie games. I especially enjoy short and sweet 2D games with an interesting concept (whether that be gameplay or narrative). That being said, I don't really upload a lot of my gaming content in public anymore, but I did use to actively create custom levels for the rhythm game *A Dance of Fire and Ice*, most of which are on my (now mostly-defunct) YouTube channel. ## Game Dev
[Sealed Secrets Journal Demo on itch.io](https://cyanaqua.itch.io/sealed-secrets-journal)

This is where a lot of the skills I learned all come together. I always wanted to be a solo game dev, which served as an inspiration for me to learn all these wonderful skills I've amassed. One of my current projects is ***Sealed Secrets Journal***, a Touhou fangame starring Renko and Maribel. This did end up being a bit too large for my first game, so I am currently working on a "miniature version", which I've named ***Hifuu Hecatolite Historia ~ Magical Night Flight***. The project is currently under heavy development, but I hope I'll be able to reveal more details soon!

I've also worked with other amazing people like **M1n3c4rt**, **TENEX_KEZIKAI**, **TeoCPerfectForm** and **0mni** as an artist for GMTK Game Jam submissions like [OXVN](https://m1n3c4rt.itch.io/oxvn) and [XCUIT](https://m1n3c4rt.itch.io/xcuit).
